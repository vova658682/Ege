Задание 6. Исполнитель Черепаха

Подключение всех команд модуля Черепаха
from turtle import *

Движение Черепахи на step пикселей вперед по направлению головы
forward(step) / fd(step)

Движение Черепахи на step пикселей назад по направлению головы
backward(step) / bk(step)

Поворот Черепахи на step градусов вправо по направлению головы
right(step) / rt(step)

Поворот Черепахи на step градусов влево по направлению головы
left(step) / lt(step)

Поднять перо
penup() / up()

Опустить перо
pendown() / down()

Телепортирует Черепаху в указанные координаты
teleport(x, y)

Рисует точку диаметром size и цветом color в текущей координате Черепахи
dot(size, color)

Изменяет размер полотна
screensize(10_000, 10_000)

Отключает анимацию
tracer(0)

Необходимо указывать вместе с tracer()
update()

Замораживает окошко
done()
